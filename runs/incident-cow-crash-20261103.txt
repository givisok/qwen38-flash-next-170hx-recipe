## Root cause
The crash is in OUR extension on top of the ported vllm#52244 mechanics, not
in upstream #52244 (upstream publishes the replay-landing state directly and
has no such assert; the producer-side CoW redirect is fork-only code).

The producer path (_cache_partial_tail_block) publishes a fine-grained
landing state for a RUNNING request and records (block_idx, source_block) +
a producer tail. The consumer path (allocate_new_blocks) assumed the
request's block table is strictly append-only between the two steps and
enforced it with a bare assert. Under replay traffic with active hash
evictions (log shows [hash-rm] runs inside the very get_new_blocks call
before the assert), the identity broke once in ~6 h of production: the
record went stale and the assert killed the engine instead of degrading.

First and only occurrence in that run (RestartCount=1; zero errors in the
preceding 6 h). Not OOM (OOMKilled=false), not the reverted #61952 port
(those files were never active in this container).

## Fix (fork commit 1000662c31 on dflash2-pool)
- Consume the partial-hit record defensively: validate BOTH identities
  (req_blocks[block_idx] and the producer marker) BEFORE any mutation.
  On mismatch: retract the unproven published hash via
  block_pool._maybe_evict_cached_block (the same tool the checkpoint branch
  uses for non-reusable states), keep the reserved cow_block as a plain new
  block of the request (plain over-allocation — an expected state per the
  surrounding code), and log a warning with all block ids. Worst case one
  landing state goes unpublished and the next replay of that prefix hits
  one hash unit shallower. Never fatal. Full diff:
  patches/prefix-replay-cow-fix.diff
- Removed the permanent cache-diag scaffolding ([hit-diag], [cache-diag],
  [rekey-diag], [mamba-lookup], [hash-ins], [hash-rm]) from
  single_type_kv_cache_manager.py, kv_cache_coordinator.py, block_pool.py.
  Its env gate checked truthiness, so VLLM_CACHE_DIAG=0 from the launcher
  kept it always on: per-step scheduler work + log spam that buried real
  errors. The launcher env line was removed too.
